论坛原则上每两周举办一次，一般安排在周三上午 9:30–12:00。常设活动地点为紫金山天文台 3 号楼 402 会议室；若涉及数据分析培训、上机实操等，可按需要延长至下午。具体日期与地点以活动日程和通知为准。

报告形式自由，鼓励互动讨论。学术报告一般建议 20–40 分钟，技能培训可适当延长。内容类型包括工作进展、研究动态、技能交流、报告演练、课程讲习及其他经讨论确定的主题。

## 联系方式

可通过论坛 GitHub Discussions 的“论坛意见与建议”分类联系组织者、提出报告主题或培训需求。论坛管理办法与详细职责请查阅最新论坛手册。
